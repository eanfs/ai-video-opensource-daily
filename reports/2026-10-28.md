## 当日趋势小结

1. **讲解视频 Skill 爆发**：一天内出现论文转视频、选题转成片、YouTube 动效板、易经动画、词根动画等多个“交给 Claude Code / Codex 出片”的项目，共同点是代码画面 + 本地 TTS + 自动核查，适合做小红书知识类竖版视频。
2. **MiniMax H3 生态成形**：ComfyUI 正式支持其 LoRA，社区随即做出本地换角色（Openjutsu）和 Colab 数字人笔记本，但门槛是 8.0 以上算力的显卡，T4 不在支持范围内。
3. **后期智能化**：FableCut 的节拍卡点/重构图/高光剪辑、HyperFrames 的音画同步修复、dsh-video-storyboard 的“一图看片”，都在把剪辑和质检交给 Agent。
4. **热度**：VoiceStudio 连续两天单日 +2000★ 以上，HyperFrames、Remotion、digital-human-koubo 也保持每天数百 Star 的增长。
